# 成长档案静态演示

学生成长档案与教师成长档案的独立静态原型，默认显示学生页面，与本地8769集成页面行为一致。页面内嵌学生及教师相关 PRD 规则。

所有人员、部门、任务、评分、评语及佐证均为合成示例。页面未接入真实业务接口、登录权限或评价提交服务。

## 本地预览

在此目录执行 `python -m http.server 8000`，访问 `http://127.0.0.1:8000/`。直接打开 `index.html` 也可运行。

学生成长档案、教师个人报告和团队分析通过页面菜单切换；所有筛选在浏览器内运行。发布文件与已验证的8769集成HTML内容一致，仅统一文本换行与运算符行尾空白，不改写默认入口或锚点逻辑。

## 教师报告 V0.8

教师成绩仅计算二级指标得分率，一级只分类。个人顶部为有效评价记录数和有效二级指标等权的平均得分率；底部评价记录支持独立活动、一级指标筛选及分页。团队删除成员和部门明细，固定两主体汇总与分项全部使用固定字段表头。

个人页面统一使用“个人报告”，报告头移除姓名与教研组；个人记录移除佐证操作。个人与团队评价表现均为全宽三列数值表，移除条形图及任务完成列，保留周期对照图。团队保留四张统计卡，移除评分任务完成度及头尾规则摘要。报告内“一级指标”只切换二级结果和分析展示，不改变统计与记录范围。

四类诊断文案按相对高低和样本状态自动匹配，包含22项模板配置及20项行动词库。右上角PRD展示完整匹配规则和词库，个人与团队规则均为九章。未新增达标线、风险分档或排名。

默认入口继续为学生页面。已在隔离浏览器核验桌面、760px、实际HTML下载及PDF打印渲染；系统打印预览未核验。所有数据仍为合成示例。
