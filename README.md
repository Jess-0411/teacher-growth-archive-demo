# 成长档案静态演示

学生成长档案与教师成长档案的独立静态原型，默认显示学生页面，与本地8769集成页面行为一致。页面内嵌学生及教师相关 PRD 规则。

所有人员、部门、任务、评分、评语及佐证均为合成示例。页面未接入真实业务接口、登录权限或评价提交服务。

## 本地预览

在此目录执行 `python -m http.server 8000`，访问 `http://127.0.0.1:8000/`。直接打开 `index.html` 也可运行。

学生成长档案、教师个人诊断和团队分析通过页面菜单切换；所有筛选在浏览器内运行。发布文件保留8769集成HTML原始内容，不改写默认入口或锚点逻辑。
